A single slogan for a Solana wallet agent, written by `main.ts` to `/output/entry.txt`.

> Your Solana wallet's doorman: opens the right doors, keeps the wrong ones shut.

## Why this line

A wallet agent stands at the door of your money: it lets the right
transactions through and keeps the wrong ones — scams, bad addresses,
shady approvals — shut out. The doorman image says that in plain words
a newcomer gets on one read, with a right/wrong contrast that sticks.

## Run

```sh
node main.ts
```

It writes the slogan (one line, 79 characters, 13 words) to `/output/entry.txt`.
